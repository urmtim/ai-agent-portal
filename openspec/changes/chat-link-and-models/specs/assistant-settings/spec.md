## MODIFIED Requirements

### Requirement: Настройки ассистента
Каждый пользователь SHALL иметь свои настройки ассистента. ✎ в строке «Ассистент» SHALL открывать то же окно, что и у агента («Общее · Политики · Субагенты · MCP · API · YAML»), с заблокированными «Агент включён» (всегда включён), «Название» («Ассистент»), «Системная инструкция» и «Тест-запуск» (проверяют в чате). В поле «Системная инструкция» SHALL показываться встроенная инструкция чата ровно в том виде, в каком её получает модель (с текущими датой, именем пользователя, почтой и разрешёнными агентами); к ней добавляются гардрейлы ассистента. Модель — одна из своих моделей, по умолчанию — модель по умолчанию. Гардрейлы ассистента (маскирование результатов почты, лимит шагов, темы, документы) MUST действовать в чате. На вкладках «Субагенты», «MCP», «API» SHALL быть табличные части с поиском, фильтром и «Добавить»; если добавить нечего, MUST показываться пояснение, где такие элементы создаются. Изменения SHALL применяться по «Сохранить» и записываться в журнал.

#### Scenario: Разрешить агента
- **WHEN** пользователь на вкладке «Субагенты» нажимает «Добавить», выбирает агента и сохраняет
- **THEN** появляется уведомление «Настройки сохранены», а при повторном открытии агент есть в таблице

#### Scenario: Убрать элемент
- **WHEN** пользователь убирает агента из таблицы на вкладке «Субагенты» и сохраняет
- **THEN** ассистент больше не может запускать этого агента, агент снова доступен для добавления

#### Scenario: Нечего добавить
- **WHEN** у пользователя нет MCP-серверов
- **THEN** на вкладке «MCP» вместо выбора — пояснение, что серверы добавляют в разделе MCP

#### Scenario: Удалённый агент
- **WHEN** разрешённого агента удалили
- **THEN** в настройках его больше нет, ассистент к нему не обращается

#### Scenario: API пока нет
- **WHEN** пользователь открывает вкладку «API»
- **THEN** таблица пуста, вместо выбора — «API портала пока нет»

#### Scenario: Заблокированные поля
- **WHEN** пользователь открывает окно «Ассистент»
- **THEN** «Агент включён», «Название», «Системная инструкция» и «Тест-запуск» видны, но недоступны, остальное редактируется

#### Scenario: Настоящая инструкция
- **WHEN** пользователь разрешил ассистенту почту «Моя почта» и открывает окно «Ассистент»
- **THEN** в «Системной инструкции» видно «ящик «Моя почта»», и модель в чате получает этот же текст
