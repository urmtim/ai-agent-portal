## MODIFIED Requirements

### Requirement: Страницы новых разделов
Разделы MCP, Модели, API и Гардрейлы SHALL открываться по адресам `/mcp`, `/models`, `/api-access`, `/guardrails` за авторизацией. Пункт «Чат» SHALL вести на `/chat/latest` — самый свежий незаархивированный чат, а если чатов нет — новый (`/chat`); пункт подсвечен на любой странице `/chat/…`. Остальные разделы ведут на существующие адреса: Обучение — `/`, Траты — `/stats`, Прогресс — `/me`, Агенты — `/agents`, Пользователи — `/admin/users`, Доступы — `/admin/access`.

#### Scenario: Неавторизованный доступ
- **WHEN** невошедший пользователь открывает `/mcp`
- **THEN** его перенаправляет на вход

#### Scenario: Чат открывает свежий
- **WHEN** пользователь на странице «Агенты» нажимает «Чат», а у него есть чаты
- **THEN** открывается чат с самым свежим сообщением, пункт «Чат» подсвечен
