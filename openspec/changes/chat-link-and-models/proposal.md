# Proposal

## Why

Замечания после деплоя: «Чат» в меню открывает пустой новый чат, а нужен самый свежий; подпись «· по умолчанию» в списке моделей окна агента лишняя; переключатели слишком бледные. Кроме того, спецификация моделей отстала от прошлого шага: модель по умолчанию уже можно удалить, а «Сделать моделью по умолчанию» — переключатель.

## What Changes

- Пункт меню «Чат» ведёт на `/chat/latest`: самый свежий незаархивированный чат, без чатов — новый. Пункт подсвечен на любой странице чата.
- В списке «Модель» окна агента и ассистента — только названия моделей, без «· по умолчанию».
- Переключатели заметнее: темнее овал в выключенном виде, плотнее тень кружка, заблокированный — почти в полный цвет.
- У встроенного агента «Ассистент» поле «Системная инструкция» показывает настоящую встроенную инструкцию чата (та же функция собирает её для модели) и заблокировано; прежняя дописка пользователя не используется.
- Спецификация моделей: «Сделать моделью по умолчанию» — переключатель; модель по умолчанию можно удалить, моделью по умолчанию становится самая ранняя из оставшихся.
- **BREAKING:** нет.
