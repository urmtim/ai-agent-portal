## ADDED Requirements

### Requirement: Вход ведёт в последний чат
После входа система SHALL открывать последний изменённый чат пользователя, не считая архивных. Если таких чатов нет, MUST открываться новый чат.

#### Scenario: Есть чаты
- **WHEN** пользователь с несколькими чатами входит в портал
- **THEN** открывается `/chat/<id>` чата, в котором было последнее сообщение

#### Scenario: Последний чат в архиве
- **WHEN** самый свежий чат пользователя отправлен в архив
- **THEN** открывается самый свежий из неархивных чатов

#### Scenario: Чатов нет
- **WHEN** у пользователя ещё нет чатов
- **THEN** открывается новый чат «Чем помочь?»
