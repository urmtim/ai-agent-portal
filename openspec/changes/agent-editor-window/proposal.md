# Proposal

## Why

Окно агента получилось обычным рядом вкладок («Общее · Инструкция · Гардрейлы · Агенты · MCP · API · YAML»), а договаривались о редакторе в духе карточки узла со скриншота: «Редактор · YAML · Настройки». Кроме того, окно прыгает при переключении вкладок — оно центрируется по высоте, а высота вкладок разная. Макет нового окна согласован: `mockups/portal-all-screens.html`, экран «Агент — окно (редактор, без графа)».

## What Changes

- Окно агента (создание и правка) — три вкладки «Редактор · YAML · Настройки».
  - «Редактор»: слева системная инструкция (у «Чеков из почты» — описание встроенного сценария), справа блоки: «HITL · запуск из чата» («Подтверждать / Сразу») и «Модель»; «MCP-инструменты», «Агенты · может запускать», «API» — плашки с «×» и «+ Добавить»; «Гардрейлы» — переключатель маскирования ПДн, лимит шагов, запрещённые темы плашками с «+ Тема» (только у «Своего агента»).
  - «YAML» — как было: текст агента, «Скачать .yaml», «Загрузить файл».
  - «Настройки»: название, тип (выбирается при создании), «Агент включён», параметры «Чеков из почты».
  - Внизу «▶ Тест-запуск» (сохраняет и сразу запускает агента) и «Сохранить» / «Создать».
- Модальные окна: верхний край закреплён; широкое окно агента — постоянного размера, прокручивается только содержимое вкладки.
- **BREAKING:** нет. Таблицы с поиском и фильтром на вкладках «Агенты / MCP / API» окна агента заменяются плашками (окно ассистента не меняется).
