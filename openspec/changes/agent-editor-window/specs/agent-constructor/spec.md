## MODIFIED Requirements

### Requirement: YAML
Окно агента SHALL иметь вкладку «YAML» с описанием всего агента (название, тип, «включён», модель, инструкция, HITL, гардрейлы, подключения MCP, агенты, API, параметры типа). Правка YAML MUST заполнять «Редактор» и «Настройки», правка в них — обновлять YAML. Пароли и токены MUST NOT попадать в YAML.

#### Scenario: Форма и YAML
- **WHEN** пользователь меняет в YAML лимит шагов на 3
- **THEN** в «Редакторе» в блоке «Гардрейлы» лимит шагов становится 3
