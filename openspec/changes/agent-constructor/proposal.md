# Proposal

## Why

Сейчас агенты — только встроенные типы с жёсткой логикой («Чеки из почты»). Пользователь хочет, чтобы агент был конструкцией, как в макете «Конструктор» и в показанном примере: системная инструкция, инструменты (MCP), другие агенты, подтверждение (HITL), ограничения (гардрейлы), YAML для импорта и экспорта и настройки. Граф из нескольких узлов — следующим шагом.

## What Changes

- Новый тип агента «Свой агент»: работает по своей инструкции с выбранными инструментами.
- Окно агента (создание и правка) для «Своего агента»: вкладки «Общее · Инструкция · Гардрейлы · Агенты · MCP · API · YAML»; для «Чеков из почты» — без «Инструкции» и «Гардрейлов».
  - «Инструкция» — системная инструкция и HITL: «Подтверждать запуск» (по умолчанию) или «Без подтверждения».
  - «Гардрейлы» — маскирование ПДн (почта, телефоны, номера карт и паспортов заменяются перед отправкой модели), лимит шагов (1–10), запрещённые темы.
  - «YAML» — весь агент текстом; правка текста заполняет форму, правка формы обновляет текст; «Скачать .yaml» и вставка или загрузка файла. Пароли и токены в YAML не попадают; модели, подключения и агенты — по названию; ненайденные названия показываются предупреждением.
- Запуск «Своего агента»: со страницы агента — с полем «Задача», из таблицы — по инструкции без задачи, из чата — ассистент передаёт задачу. Агент работает с инструментами своих подключений (сейчас «Почта») и может звать разрешённых агентов, которые не требуют подтверждения. Прогон пишет журнал шагов и итог в историю.
- В чате ассистент спрашивает подтверждение запуска только у агентов с HITL «Подтверждать запуск».
- **BREAKING:** нет.

## Capabilities

### New Capabilities
- `agent-constructor`: «Свой агент» — инструкция, HITL, гардрейлы, YAML, выполнение.

### Modified Capabilities
- `agents-list`: тип «Свой агент» при создании, вкладки окна, запуск с задачей.
- `chat`: запуск агента с задачей, подтверждение по HITL агента.

## Impact

- Prisma: `AgentType.CUSTOM`, `Agent.instruction`, `Agent.hitl`, `Agent.guardrails` (JSON), `prisma db push`.
- Зависимость `yaml`.

- `app/(app)/agents/` (окно, действия, страница агента), `lib/chat/tools.ts`, `app/api/chat/route.ts`, `app/(app)/chat/ChatParts.tsx`.
