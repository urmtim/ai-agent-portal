# Proposal

## Why

Окно агента с плашками не прижилось. На макете (`mockups/portal-all-screens.html`, экраны «Агент — окно: новый / правка») согласовано новое: обычные вкладки с табличными частями, политики (HITL и гардрейлы) отдельной вкладкой с выключателями, доступ к каждому подключению MCP, одинаковое окно для создания и правки, без встроенных типов. HITL по смыслу — подтверждение действий с последствиями (изменение, отправка), а не запуска.

## What Changes

- Окно агента (создание и правка — одно и то же, отличается только заголовком «Новый агент» / название): вкладки «Общее · Политики · Субагенты · MCP · API · YAML», внизу «▶ Тест-запуск» и «Сохранить».
  - «Общее»: выключатель «Агент включён», Название, Модель (только свои модели, у нового — модель по умолчанию, подписана «· по умолчанию»), Системная инструкция — каждое поле на своей строке.
  - «Политики»: выключатель «Человек в контуре (HITL)» и выбор «Спрашивать перед изменением и отправкой» / «Спрашивать только перед отправкой»; выключатель «Гардрейлы» и табличная часть правил (поиск, фильтр, «Добавить»): «Маскирование ПДн», «Лимит шагов — N», «Запрещённая тема — …» (тем может быть несколько).
  - «Субагенты», «MCP», «API» — табличные части; у MCP колонка «Доступ»: «только чтение» / «чтение и отправка».
  - «YAML»: крупный шрифт и подсветка, внизу слева «Скачать .yaml» и «Загрузить .yaml».
- Выключатели — в стиле iOS, синие; выпадающие списки портала — со своей стрелкой.
- Окно ниже (12 % высоты экрана), постоянного размера.
- Встроенного типа «Чеки из почты» в интерфейсе больше нет: новые агенты — «Свои»; существующие «Чеки» превращаются в «Своих» с инструкцией про чеки (больше не пишут в «Траты»).
- Пока не сделан следующий шаг (подтверждение перед конкретным действием, соблюдение доступа): включённый HITL спрашивает перед запуском агента из чата, выключенный — нет; субагентом может быть только агент с выключенным HITL; доступ MCP хранится, но инструменты почты и так только читают.
- **BREAKING:** формат YAML меняется (`hitl: {enabled, ask}`, `guardrails: {enabled, rules}`, `mcp: [{name, access}]`, без `type`); старый формат читается.
