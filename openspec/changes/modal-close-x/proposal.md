# Proposal

## Why

Модалки закрываются случайным кликом мимо окна, и всё введённое теряется. Пользователь хочет закрывать их только явно.

## What Changes

- Модальное окно закрывается только крестиком «×» и своими кнопками («Отмена», «Готово», после успешного сохранения).
- Клик по затемнённому фону и клавиша Esc окно больше не закрывают.
- **BREAKING:** нет.

### Modified Capabilities

## Impact

- `components/ui/Modal.tsx` (`Modal`, а через него `ConfirmModal`): все модалки портала — пользователи, агенты, модели, удаление чата.
