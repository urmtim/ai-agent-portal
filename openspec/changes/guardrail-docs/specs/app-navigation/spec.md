## MODIFIED Requirements

### Requirement: Вкладки раздела AI
На страницах Агенты, Модели, MCP, API и Гардрейлы под заголовком SHALL показываться вкладки «Агенты · Модели · MCP · API · Гардрейлы», текущая выделена. Клик по вкладке открывает соответствующую страницу. Раздел «Гардрейлы» (`/guardrails`) SHALL быть и в трее разделов, в группе AI.

#### Scenario: Переход вкладкой
- **WHEN** пользователь на странице «Агенты» нажимает вкладку «Модели»
- **THEN** открывается `/models`, выделена вкладка «Модели»

#### Scenario: Гардрейлы
- **WHEN** пользователь на странице «Агенты» нажимает вкладку «Гардрейлы»
- **THEN** открывается `/guardrails`, выделена вкладка «Гардрейлы»
