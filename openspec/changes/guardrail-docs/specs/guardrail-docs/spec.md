## ADDED Requirements

### Requirement: Каталог документов-гардрейлов
Раздел «Гардрейлы» (`/guardrails`) SHALL показывать документы-гардрейлы текущего пользователя таблицей: ID, Название (с описанием), Файл (имя и размер), Используют (сколько агентов), Статус («включён» / «выключен»). «Добавить документ» и ✎ SHALL открывать окно: название, описание, файл (docx, pdf, txt, md, до 4 МБ), «Включён». Из файла MUST доставаться текст; файл без текста MUST отклоняться понятной ошибкой. Чужие документы MUST NOT показываться. Добавление, правка и удаление пишутся в журнал.

#### Scenario: Загрузить документ
- **WHEN** пользователь загружает «Регламент.docx» и сохраняет
- **THEN** в таблице появляется строка с названием, именем файла и статусом «включён»

#### Scenario: Неподходящий файл
- **WHEN** пользователь выбирает картинку или файл больше 4 МБ
- **THEN** окно показывает ошибку и не сохраняет

### Requirement: Документ в агенте
Документ SHALL добавляться агенту на вкладке «Политики» в таблицу гардрейлов с видом «документ». При выполнении агента текст его включённых документов MUST передаваться модели как обязательные правила. Выключенный в каталоге документ MUST NOT применяться; удалённый — пропадает из агентов.

#### Scenario: Правила из документа
- **WHEN** у агента документ с текстом «Не называй суммы в ответах» и агент запускается
- **THEN** модель получает этот текст в инструкции как обязательное правило

#### Scenario: Выключенный документ
- **WHEN** документ выключен в разделе «Гардрейлы»
- **THEN** его текст модели не передаётся
