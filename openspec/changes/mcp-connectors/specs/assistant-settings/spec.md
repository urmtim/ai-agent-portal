## MODIFIED Requirements

### Requirement: Настройки ассистента
Каждый пользователь SHALL иметь свои настройки ассистента в модальном окне «Ассистент» на странице «Агенты»: вкладки «Общее» (модель: «По умолчанию» или модель из реестра), «Агенты», «MCP», «API» с табличными частями разрешённого. На вкладке SHALL быть поиск, фильтр, кнопка «Добавить» справа над таблицей (выбор из ещё не добавленных элементов) и таблица добавленных элементов (Название, Описание, кнопка «Убрать») (свои агенты пользователя, его подключения из раздела MCP, API портала — пока ни одного). Если добавить нечего, вместо выбора MUST показываться пояснение, где такие элементы создаются. Изменения SHALL применяться по «Сохранить» и записываться в журнал.

#### Scenario: Разрешить агента
- **WHEN** пользователь на вкладке «Агенты» нажимает «Добавить», выбирает «Чеки из почты» и сохраняет
- **THEN** появляется уведомление «Настройки сохранены», а при повторном открытии агент есть в таблице

#### Scenario: Убрать элемент
- **WHEN** пользователь убирает агента из таблицы на вкладке «Агенты» и сохраняет
- **THEN** ассистент больше не может запускать этого агента, агент снова доступен для добавления

#### Scenario: Нечего добавить
- **WHEN** у пользователя нет MCP-серверов
- **THEN** на вкладке «MCP» вместо выбора — пояснение, что серверы добавляют в разделе MCP

#### Scenario: Удалённый агент
- **WHEN** разрешённого агента удалили
- **THEN** в настройках его больше нет, ассистент к нему не обращается

#### Scenario: API пока нет
- **WHEN** пользователь открывает вкладку «API»
- **THEN** таблица пуста, вместо выбора — «API портала пока нет»
