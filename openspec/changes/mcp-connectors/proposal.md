# Proposal

## Why

Пользователь хочет портал как WorkAist: раздел MCP — каталог коннекторов к внешним сервисам, а агенты — сценарии поверх коннекторов. Почта сейчас задаётся в `.env` (один ящик на портал), агент чеков читает её оттуда, а ассистент почту не видит вовсе. Нужно: у каждого свой ящик, подключённый в портале; агент чеков и ассистент получают почту через вкладку MCP.

## What Changes

- Раздел MCP (`/mcp`) — таблица подключений пользователя: ID, Название, Коннектор, Инструменты, Кто использует, Статус. «Добавить» у таблицы, действия «Проверить», «Изменить», «Удалить», клик по строке — правка. Подключения личные: каждый видит и использует только свои.
- Каталог коннекторов, первый — «Почта» (IMAP): почтовый сервис (Mail.ru, Яндекс, Gmail или другой — адрес сервера и порт), логин, пароль приложения, SSL. Пароль хранится зашифрованным, в браузер не отдаётся; пустое поле при правке оставляет прежний. «Проверить» подключается к ящику и показывает результат.
- Инструменты коннектора «Почта»: «Искать письма» (за N дней, по тексту/отправителю, только непрочитанные) и «Прочитать письмо». Чтение не помечает письма прочитанными. Отправки писем нет.
- Агент «Чеки из почты» берёт ящик из своей вкладки MCP; `.env` (`IMAP_*`) больше не используется. Без подключённой почты прогон завершается понятной ошибкой.
- Ассистент: почтовые подключения на вкладке MCP дают ему в чате инструменты «Искать письма» и «Прочитать письмо» — разбор почты по запросу («что важного пришло за день?»).
- Колонка MCP в «Агентах» показывает подключения агента; предупреждение про почту говорит, куда её подключить.
- Добавление, правка, проверка, удаление подключений и обращения ассистента к почте пишутся в журнал (без паролей и текста писем).
- **BREAKING:** почта из `.env` больше не читается — ящик нужно подключить в разделе MCP.

## Capabilities

### New Capabilities
- `mcp-connectors`: каталог коннекторов, подключения пользователя, коннектор «Почта» и его инструменты.

### Modified Capabilities
- `agents-list`: колонка MCP и предупреждение про почту.
- `assistant-settings`: вкладка MCP — подключения пользователя.
- `chat`: почтовые инструменты ассистента.

## Impact

- Prisma: модель `McpConnection` (владелец, коннектор, название, настройки JSON, зашифрованный секрет, результат проверки), `prisma db push`.
- `lib/connectors.ts` (каталог, пресеты почты, чистые функции с тестами), `lib/mailbox.ts` (подключение по настройкам, поиск, чтение, проверка), `lib/agents/receipts.ts`, `lib/agents/runner.ts`.
- `app/(app)/mcp/` — страница, модалки, действия.
- `lib/assistant.ts`, `lib/assistant-config.ts`, `lib/chat/tools.ts`, `app/api/chat/route.ts`, `app/(app)/chat/ChatParts.tsx`, `ChatThread.tsx`, `data.ts`, `app/(app)/agents/` (MCP-вкладки, таблица, предупреждение), `lib/audit-events.ts`.
