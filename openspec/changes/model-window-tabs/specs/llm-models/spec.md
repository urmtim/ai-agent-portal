## MODIFIED Requirements

### Requirement: Добавление и изменение модели
Кнопка «Добавить модель» и иконка «Изменить» SHALL открывать окно того же размера, что окно агента, с заголовком «Новая модель» или названием модели и вкладками «Общее · YAML».
- «Общее»: «Сделать моделью по умолчанию» (переключатель), Название, Адрес API (обязательно, http/https), Модель (обязательно), Токен (скрытый ввод с кнопкой показа), Контекст, токенов (2 000–2 000 000, по умолчанию 32 000) — каждое поле на своей строке.
- «YAML»: название, адрес, модель, контекст и «по умолчанию» текстом с подсветкой; правка YAML заполняет «Общее», правка «Общего» — YAML; «Скачать .yaml» и «Загрузить .yaml». Токен MUST NOT попадать в YAML; токен из загруженного YAML MUST NOT браться (предупреждение).
- Внизу — «Проверить» и «Сохранить».
- Пустое название заменяется идентификатором модели.
- Первая добавленная модель автоматически становится моделью по умолчанию.
- «Контекст, токенов» — сколько модель держит в памяти; по нему чат решает, когда пересказывать начало.

#### Scenario: Добавить
- **WHEN** администратор заполняет адрес `http://localhost:11434/v1` и модель `llama3.1` и нажимает «Сохранить»
- **THEN** окно закрывается, появляется «Модель добавлена», в таблице новая строка

#### Scenario: Некорректный адрес
- **WHEN** в «Адрес API» введено `localhost:11434`
- **THEN** окно показывает ошибку «Адрес должен начинаться с http:// или https://»

#### Scenario: Контекст
- **WHEN** пользователь указывает «Контекст, токенов» 8000 и сохраняет
- **THEN** при следующем открытии в поле 8000

#### Scenario: Модель из YAML
- **WHEN** пользователь вставляет на вкладке «YAML» описание модели с адресом и токеном
- **THEN** «Общее» заполняется адресом и моделью, токен не подставляется, видно предупреждение
