## MODIFIED Requirements

### Requirement: Модель по умолчанию
Ровно одна модель SHALL быть моделью по умолчанию, если в реестре есть хотя бы одна модель. Переключатель «Сделать моделью по умолчанию» снимает этот признак с прежней; у самой модели по умолчанию он включён и заблокирован. Если у пользователя ещё нет моделей, в окне новой модели переключатель MUST быть включён и заблокирован с пояснением, что первая модель всегда становится моделью по умолчанию. В списках выбора модели (окно агента, ассистента) подписи «по умолчанию» нет — модель по умолчанию просто выбрана у нового агента.

#### Scenario: Сменить модель по умолчанию
- **WHEN** администратор включает «Сделать моделью по умолчанию» у Llama и сохраняет
- **THEN** пометка «по умолчанию» переходит с GLM-4 на Llama

#### Scenario: Первая модель
- **WHEN** у пользователя нет моделей и он открывает «Добавить модель»
- **THEN** «Сделать моделью по умолчанию» включён, изменить его нельзя, видно «Это первая модель — она всегда становится моделью по умолчанию»
