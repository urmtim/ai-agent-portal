# Proposal

## Why

В окне «Базовый ассистент» агенты, MCP и API показаны общими списками с галочками. Пользователь хочет табличные части: на отдельной вкладке для каждого вида — таблица добавленных элементов, куда элементы добавляют и откуда их убирают.

## What Changes

- Под полем «Модель» — вкладки «Агенты · MCP · API» с числом добавленных элементов.
- На каждой вкладке — таблица добавленных элементов (Название, Описание, ✕ убрать) и строка добавления: выбор из ещё не добавленных элементов и кнопка «Добавить». Пустая таблица — «Пока ничего не добавлено».
- Если добавить нечего (нет MCP-серверов, нет агентов), вместо выбора — пояснение, где их создать.
- Изменения применяются по «Сохранить», как раньше.
- **BREAKING:** нет.
