# Proposal

## Why

Окна агента и ассистента узкие, а настройки разнородные. Пользователь хочет окно шире и с вкладками: первая — «Общее», дальше «Агенты», «MCP», «API». На вкладках со списками — как на страницах-таблицах: поиск, фильтр и кнопка «Добавить» прямо у таблицы.

## What Changes

- Окна «Новый агент», «Изменить агента» и «Ассистент» — широкие, с вкладками «Общее · Агенты · MCP · API».
- «Общее»: у агента — тип (при создании), название, модель, параметры типа (за сколько дней, макс. писем, фильтр по отправителю) и «Агент включён»; у ассистента — модель.
- «Агенты», «MCP», «API» — табличные части: поиск, «+ Фильтр» (у агентов — по состоянию), «Добавить» справа над таблицей открывает список того, что ещё можно добавить; в строке — «Убрать».
- У обычного агента появляются свои списки разрешённых агентов (кроме него самого), MCP-серверов и API. Пока агент «Чеки из почты» ими не пользуется — это видно в подсказке; списки начнут действовать, когда агенты научатся звать других агентов, MCP и API.
- Создание и правка агента — одно действие; сохранение пишется в журнал.
- **BREAKING:** нет.
