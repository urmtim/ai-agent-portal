## MODIFIED Requirements

### Requirement: Выбор модели
Чат — это ассистент: он SHALL отвечать моделью, заданной в настройках ассистента, а если там «По умолчанию» — моделью по умолчанию из реестра. Выбора модели в самом чате MUST NOT быть. Если реестр пуст, а модель задана в `.env`, чат SHALL работать на ней без выбора. Если модели нет нигде, чат SHALL показывать предупреждение со ссылкой на «Модели», а отправка MUST быть недоступна.

#### Scenario: Смена модели
- **WHEN** пользователь меняет модель в настройках ассистента и отправляет сообщение в любом чате
- **THEN** ответ генерирует новая модель ассистента; в шапке чата выбора модели нет

#### Scenario: Модель удалили
- **WHEN** модель ассистента удалена из реестра
- **THEN** чат отвечает моделью по умолчанию

#### Scenario: Нет ни одной модели
- **WHEN** в реестре нет моделей и в `.env` модель не задана
- **THEN** вместо ответа видно предупреждение со ссылкой на «Модели», кнопка отправки неактивна

### Requirement: История чатов
Боковая панель SHALL показывать чаты пользователя, новые сверху, в группах «Закреплённые», «Сегодня», «Вчера», по дате для последней недели, «Ранее» и свёрнутой «Архив». Пустые группы MUST не показываться. Панель SHALL содержать «+ Новый чат», поиск по названиям и для каждого чата действия «Закрепить»/«Открепить», «В архив»/«Из архива», «Удалить» (с подтверждением). На широком экране панель SHALL быть по умолчанию скрыта и показываться кнопкой в шапке чата; выбор MUST запоминаться в браузере. На узком экране панель SHALL открываться той же кнопкой поверх ленты.

#### Scenario: Поиск
- **WHEN** пользователь вводит часть названия в поиск
- **THEN** остаются только подходящие чаты, группы без совпадений скрываются

#### Scenario: Закрепление
- **WHEN** пользователь закрепляет чат
- **THEN** чат переходит в группу «Закреплённые» вверху списка

#### Scenario: Архив
- **WHEN** пользователь отправляет чат в архив
- **THEN** чат пропадает из обычных групп и виден только в группе «Архив»

#### Scenario: Удаление открытого чата
- **WHEN** пользователь подтверждает удаление чата, который сейчас открыт
- **THEN** чат удаляется и открывается новый пустой чат

#### Scenario: История скрыта по умолчанию
- **WHEN** пользователь впервые открывает чат на широком экране
- **THEN** панели истории не видно; кнопка в шапке показывает её, и при следующем открытии чата она видна
