# Proposal

## Why

- Кнопка добавления («Добавить модель», «Новый агент», «Добавить пользователя») стоит в шапке страницы, далеко от таблицы; пользователь хочет её рядом с таблицей — в строке с поиском.
- У базового ассистента ID «—»; пользователь хочет, чтобы он был «#1», а остальные агенты нумеровались после него.

## What Changes

- Кнопка добавления — справа в строке поиска и фильтра, прямо над таблицей, на страницах «Модели», «Агенты», «Пользователи».
- Базовый ассистент — «#1», агенты пользователя — «#2», «#3»… в порядке создания.
- **BREAKING:** нет.
