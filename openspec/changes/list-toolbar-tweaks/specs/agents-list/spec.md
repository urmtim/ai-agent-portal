## MODIFIED Requirements

### Requirement: Базовый ассистент
Первой строкой таблицы SHALL идти «Базовый ассистент» с пометкой «встроенный» и ID «#1» (агенты пользователя нумеруются с «#2» в порядке создания): его модель, разрешённые MCP-серверы и краткая сводка разрешённого (агенты, API). Клик по строке или иконка «Изменить» SHALL открывать модальное окно «Базовый ассистент» с его настройками. Строку нельзя удалить или запустить; она не участвует в фильтре по статусу.

#### Scenario: Пустой список
- **WHEN** у пользователя нет своих агентов
- **THEN** в таблице только строка «Базовый ассистент»

#### Scenario: Открыть настройки
- **WHEN** пользователь кликает по строке «Базовый ассистент»
- **THEN** открывается окно «Базовый ассистент» с его настройками
