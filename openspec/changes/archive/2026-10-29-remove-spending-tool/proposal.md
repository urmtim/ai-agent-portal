# Proposal

## Why

Пользователь просит убрать «Траты» из ассистента: в списке API это был единственный пункт, и он путал — «откуда траты взялись».

## What Changes

- Инструмент чата «Траты» больше не предлагается модели; в настройках ассистента на вкладке «API» пусто — «API портала пока нет».
- Из подсказок пустого чата и из указаний модели убраны траты.
- В уже сохранённых чатах прежние вызовы «Трат» по-прежнему отображаются (история не ломается); новые вызовы невозможны.
- Раздел «Траты» (`/stats`) в группе «Семья» не меняется.
- **BREAKING:** ассистент больше не отвечает о тратах по чекам.
