# Proposal

## Why

Сейчас портал знает ровно одну LLM: адрес, модель и токен задаются в `.env`, а поменять их можно только правкой файла и перезапуском. В макете раздел «Модели» — это таблица: моделей может быть несколько (облачная GLM, локальная Llama в Ollama). Одна из них по умолчанию, у агента может быть своя модель. Без реестра моделей не будет ни выбора модели для агента, ни чата, ни конструктора.

## What Changes

- Новая таблица моделей в базе:
  - поля: название, адрес API (OpenAI-совместимый, до `/v1`), идентификатор модели, токен, признак «по умолчанию»;
  - результат последней проверки.
- Токен хранится в базе в зашифрованном виде (ключ выводится из `AUTH_SECRET`). В браузер он никогда не отдаётся: при правке поле пустое, пустое значение оставляет прежний токен.
- Страница `/models` по макету:
  - таблица: ID, Название (с пометкой «по умолчанию»), Адрес API, Агенты, Статус;
  - действия: проверить, изменить, удалить;
  - модель по умолчанию удалить нельзя.
- Модалка «Новая модель» / «Изменить модель»:
  - поля Название, Адрес API*, Модель*, Токен (со «глазом»), «Сделать моделью по умолчанию»;
  - «Проверить» — пробный запрос к модели без сохранения;
  - «Сохранить».
- Управлять моделями может только администратор, остальные видят таблицу без действий.
- У агента появляется выбор модели на его странице: «По умолчанию» или конкретная. Колонка «Модель» в таблице агентов показывает фактическую модель.
- LLM-клиент берёт модель агента, иначе модель по умолчанию из базы, иначе — как раньше — `LLM_*` из `.env`. Текущие установки продолжают работать без миграции.
- **BREAKING:** нет.

## Capabilities

### New Capabilities
- `llm-models`: реестр LLM-моделей — хранение (включая защиту токена), модель по умолчанию, проверка подключения, страница «Модели», выбор модели агентом и порядок выбора модели при вызове.

### Modified Capabilities
- `agents-list`: колонка «Модель» показывает модель агента или модель по умолчанию, предупреждение о `.env` учитывает модели из реестра.

## Impact

- Prisma:
  - новая модель `LlmModel`;
  - поле `Agent.modelId` (необязательное, при удалении модели обнуляется);
  - `prisma db push`.
- Код:
  - `lib/llm.ts` — выбор модели и проверка подключения;
  - новый `lib/secret.ts` — шифрование;
  - `app/(app)/models/*`;
  - `app/(app)/agents/page.tsx`, `app/(app)/agents/[id]/page.tsx`, `app/(app)/agents/actions.ts`;
  - `lib/agents/receipts.ts` — передача модели агента.
- Безопасность:
  - запрос «Проверить» уходит на адрес, который ввёл администратор, — доступно только администратору;
  - токен не логируется и не возвращается клиенту.
