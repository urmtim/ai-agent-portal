# Proposal

## Why

Администратор не видит, что происходит в портале: кто входил, кого пригласили, какие модели меняли, какие агенты запускались и кто подтвердил запуск из чата. На портале лицензий для этого есть «Журнал» — та же страница нужна здесь, и писать в неё нужно всё.

## What Changes

- Новый журнал событий в базе: время, кто (пользователь или «Система»), событие, канал (портал / чат / система), детали.
- В журнал пишется всё значимое:
  - вход, неудачная попытка входа, выход;
  - пользователи: приглашение, повторное приглашение, принятие приглашения, изменение, удаление; доступы к курсам;
  - модели: добавление, изменение, удаление, проверка;
  - агенты: создание, изменение настроек, удаление, запуск (из «Агентов» или из чата) с результатом;
  - чат: создание и удаление чата, закрепление и архив, подтверждение или отказ в запуске агента, вызов инструмента «Траты»;
  - обучение: пройденный урок, результат теста.
  - Текст сообщений чата и пароли в журнал не попадают.
- Страница «Журнал» (`/admin/log`) только для администратора, по образцу портала лицензий:
  - заголовок с числом записей;
  - поиск по пользователю, событию и деталям; «+ Фильтр» по событию и каналу;
  - таблица: Дата, Пользователь, Событие (цветная метка), Канал, Детали; новые сверху;
  - постраничный вывод по 50 записей.
- В меню «Все разделы» в группе «Админ» появляется пункт «Журнал».
- **BREAKING:** нет.

## Capabilities

### New Capabilities
- `audit-log`: запись событий портала и страница «Журнал».

### Modified Capabilities
- `app-navigation`: группа «Админ» в трее получает пункт «Журнал».

## Impact

- Prisma: модель `AuditLog`, `prisma db push`.
- `lib/audit.ts` — запись события (ошибка записи не ломает основное действие), справочник событий.
- Вызовы записи в `auth.ts`, `app/actions/auth.ts`, `app/invite/actions.ts`, `app/(app)/admin/actions.ts`, `app/(app)/models/actions.ts`, `app/(app)/agents/actions.ts`, `lib/agents/runner.ts`, `app/api/chat/route.ts`, `lib/chat/tools.ts`, `app/(app)/chat/actions.ts`, `app/actions/progress.ts`, `app/api/quiz/route.ts`.
- `app/(app)/admin/log/page.tsx`, `lib/nav.ts`.
