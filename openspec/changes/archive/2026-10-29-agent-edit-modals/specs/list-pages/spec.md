## MODIFIED Requirements

### Requirement: Открытие записи кликом по строке
Клик по строке таблицы SHALL открывать редактирование этой записи — то же, что кнопка правки в строке (окно правки модели, пользователя или агента). Клик по кнопке, ссылке или полю в строке MUST выполнять их собственное действие, а выделение текста и клики внутри открытого окна MUST NOT открывать правку. Строки без правки (например, встроенный «Базовый ассистент») на клик не реагируют. Открываемая строка SHALL подсвечиваться при наведении.

#### Scenario: Клик по строке модели
- **WHEN** администратор кликает по названию модели в таблице «Модели»
- **THEN** открывается окно «Изменить модель» этой модели

#### Scenario: Клик по иконке удаления
- **WHEN** пользователь кликает по иконке удаления в строке
- **THEN** открывается подтверждение удаления, а не окно правки

#### Scenario: Клик по строке агента
- **WHEN** пользователь кликает по строке своего агента
- **THEN** открывается окно «Изменить агента»
