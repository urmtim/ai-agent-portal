# Proposal

## Why

В макете списки сделаны таблицами, как в портале лицензий: строка поиска, «+ Фильтр», колонка ID, иконки действий в строке; создание идёт через модалки. Сейчас «Пользователи» — это форма над таблицей, а «Агенты» — карточки с одной жёстко зашитой кнопкой создания. Приводим к макету два раздела с реальными данными. Заодно появляются общие таблица, модалка и тост, на которых потом будут собраны MCP и Модели.

## What Changes

- Общий вид списков:
  - панель с поиском по строкам и кнопкой «+ Фильтр» (выпадающий список с отметками);
  - таблица в карточке с горизонтальной прокруткой на узких экранах;
  - колонка ID — порядковый номер `#N`;
  - иконки действий справа.
- Общая модалка (заголовок, подзаголовок, крестик, подвал с кнопками; закрытие по Esc и клику по фону) и всплывающее уведомление (тост).
- Вкладки «Агенты · MCP · Модели» под заголовком на страницах раздела AI.
- **Пользователи** (`/admin/users`):
  - кнопка «+ Добавить пользователя» открывает модалку «Новый пользователь» (E-mail*, Имя, Фамилия, Роль);
  - форма над таблицей убирается;
  - колонки: ID, Пользователь, Роль, Статус, Создан;
  - действия: выслать приглашение снова (для приглашённых), изменить (модалка: имя, роль, включён/отключён), удалить (с подтверждением).
  - **BREAKING:** администратор не может удалить или отключить себя и последнего администратора.
- **Агенты** (`/agents`):
  - кнопка «+ Новый агент» открывает модалку с выбором типа (пока только «Чеки из почты») и названием;
  - карточки заменяет таблица: ID, Название с описанием и ссылкой на страницу агента, Модель, MCP, Статус, Последний прогон;
  - первая строка — неактивный «Базовый ассистент»;
  - действия: запустить, настроить (страница агента), удалить (с подтверждением).

## Capabilities

### New Capabilities
- `list-pages`: общее поведение страниц-списков — поиск, фильтр, нумерация строк, иконки действий, модалки и уведомления.
- `user-admin`: управление пользователями администратором — список, приглашение, повторная отправка, изменение, отключение и удаление.
- `agents-list`: список агентов пользователя — создание, запуск, удаление, базовый ассистент.

### Modified Capabilities
- `app-navigation`: добавляются вкладки раздела AI.

## Impact

- Код:
  - `app/(app)/admin/users/*`, `app/(app)/admin/actions.ts`;
  - `app/(app)/agents/page.tsx`, `app/(app)/agents/actions.ts`;
  - новые общие компоненты в `components/ui/*`;
  - `app/globals.css`;
  - заглушки `mcp` и `models` получают вкладки AI.
- Данные: схема Prisma не меняется. Удаление пользователя каскадно удаляет его агентов, чеки и прогресс (каскад уже задан в схеме).
- Зависимости: новых нет.
