# Spec Delta

## ADDED Requirements

### Requirement: Вкладки раздела AI
На страницах Агенты, MCP и Модели под заголовком SHALL показываться вкладки «Агенты · MCP · Модели», текущая выделена. Клик по вкладке открывает соответствующую страницу.

#### Scenario: Переход вкладкой
- **WHEN** пользователь на странице «Агенты» нажимает вкладку «Модели»
- **THEN** открывается `/models`, выделена вкладка «Модели»
