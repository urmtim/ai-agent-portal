# Proposal

## Why

Раздел «Чат» сейчас заглушка, а по макету это главный экран портала: ассистент, который отвечает на вопросы и сам запускает агентов. Модели уже есть в реестре («Модели»), агенты есть в «Агентах», не хватает места, где с ними разговаривают. Идеи взяты из Open WebUI (история слева, выбор модели, кнопки под сообщениями, видимые вызовы инструментов), но экран свой, по макету.

## What Changes

- Страница `/chat` по макету: история чатов слева, лента сообщений, поле ввода снизу. `/chat/<id>` открывает сохранённый чат.
- История чатов:
  - сгруппирована по датам: «Сегодня», «Вчера», дата, «Ранее»;
  - поиск по названиям;
  - закрепление (группа «Закреплённые» сверху), архив (свёрнутая группа «Архив» снизу), удаление с подтверждением;
  - название чата модель придумывает сама после первого ответа; если не смогла — берётся начало первого сообщения.
- Выбор модели в шапке чата: модели из реестра, по умолчанию модель по умолчанию. Выбор запоминается в чате.
- Ответ печатается по мере генерации. Пока идёт ответ, кнопка отправки становится «Остановить».
- Кнопки под сообщениями:
  - у ответа: «Копировать», «Повторить» (только у последнего);
  - у своего сообщения: «Копировать», «Изменить» (правка отбрасывает всё после него и отправляет заново).
- Инструменты ассистента:
  - «Траты» — сводка трат пользователя за период, без подтверждения (только чтение);
  - «Запустить агента» — запуск одного из своих агентов, только после подтверждения в чате (карточка «⏸ Нужно подтверждение» с кнопками «Запустить» / «Отмена»).
  - Каждый вызов виден в ленте строкой, которая раскрывается в подробности.
- Чаты видит и меняет только их владелец.
- **BREAKING:** нет.

## Capabilities

### New Capabilities
- `chat`: чат с ассистентом — хранение и история чатов, выбор модели, потоковый ответ и управление им, действия над сообщениями, инструменты ассистента и подтверждение действий.

### Modified Capabilities
<!-- нет -->

## Impact

- Prisma: новая модель `Chat` (владелец, название, модель, закреплён, в архиве, сообщения JSON), `prisma db push`.
- Зависимости: `ai`, `@ai-sdk/react`, `@ai-sdk/openai-compatible` (Vercel AI SDK 7).
- Код:
  - `app/api/chat/route.ts` — потоковый ответ, инструменты, сохранение;
  - `app/(app)/chat/` — страницы, клиентский экран, server actions для списка;
  - `lib/chat/` — модель для AI SDK, инструменты, названия и группировка по датам (с тестами);
  - `app/globals.css` — стили чата из макета.
- Вне объёма (следующие поставки): шаблоны по `/`, память, подсказки следующего вопроса, временный чат, голосовой ввод, вложения, диспетчер с выбором среди многих агентов, MCP.
