## MODIFIED Requirements

### Requirement: Трей всех разделов
Кнопка «Все разделы» SHALL раскрывать под шапкой трей с группами: «Основное» (Чат), «AI» (Агенты, Модели, MCP, API), «Семья (скрыто)» (Обучение, Траты, Прогресс), «Админ» (Пользователи, Доступы, Журнал). Пункты группы «Семья» MUST показываться приглушённым стилем, остальные — обычным. Трей SHALL закрываться повторным нажатием кнопки, клавишей Esc и переходом в раздел.

#### Scenario: Открыть и перейти
- **WHEN** пользователь нажимает «Все разделы» и выбирает «MCP»
- **THEN** открывается страница MCP и трей закрывается

#### Scenario: Закрыть по Esc
- **WHEN** трей открыт и пользователь нажимает Esc
- **THEN** трей закрывается

#### Scenario: Выбор с клавиатуры
- **WHEN** фокус на пункте трея и пользователь нажимает Enter
- **THEN** открывается этот раздел

### Requirement: Закреплённые пункты верхнего меню
Верхнее меню SHALL показывать закреплённые пункты в сохранённом порядке. Если пользователь ничего не настраивал, закреплены Чат, Агенты, Модели, MCP, API. Сохранённые прежние меню по умолчанию (Чат, Агенты, MCP, Модели и Чат, Агенты, Модели, MCP, API) SHALL заменяться новым; меню, изменённое пользователем, MUST сохраняться как есть. Закрепляются только пункты групп, не сами группы.

#### Scenario: Меню по умолчанию
- **WHEN** пользователь впервые открывает портал в браузере
- **THEN** в меню по порядку: Чат, Агенты, Модели, MCP, API

#### Scenario: Прежнее меню по умолчанию
- **WHEN** в браузере сохранено меню Чат, Агенты, MCP, Модели
- **THEN** показывается новое меню Чат, Агенты, Модели, MCP, API

#### Scenario: Своё меню
- **WHEN** пользователь раньше сам поменял меню на Чат, Траты, Агенты
- **THEN** меню остаётся Чат, Траты, Агенты

### Requirement: Закрепление и открепление перетаскиванием
Перетаскивание пункта из трея в меню SHALL закреплять его в позиции отпускания. Перетаскивание пункта из меню в трей SHALL откреплять его. Последний закреплённый пункт MUST NOT откреплиться. Во время перетаскивания меню MUST показывать место вставки.

#### Scenario: Закрепить из трея
- **WHEN** пользователь перетаскивает «Траты» из трея между «Чат» и «Агенты»
- **THEN** меню становится: Чат, Траты, Агенты, Модели, MCP, API

#### Scenario: Открепить в трей
- **WHEN** пользователь перетаскивает «MCP» из меню в трей
- **THEN** «MCP» исчезает из меню

#### Scenario: Последний пункт
- **WHEN** в меню один пункт и его перетаскивают в трей
- **THEN** пункт остаётся в меню

### Requirement: Вкладки раздела AI
На страницах Агенты, Модели, MCP и API под заголовком SHALL показываться вкладки «Агенты · Модели · MCP · API», текущая выделена. Клик по вкладке открывает соответствующую страницу.

#### Scenario: Переход вкладкой
- **WHEN** пользователь на странице «Агенты» нажимает вкладку «Модели»
- **THEN** открывается `/models`, выделена вкладка «Модели»
