# Proposal

## Why

- Пользователь привык закрывать окно клавишей Esc; запрещать нужно было только случайный клик мимо окна.
- В таблице «Модели» адрес API малополезен, а нужный идентификатор модели прячется мелкой строкой под названием.

## What Changes

- Модальные окна закрываются крестиком «×», клавишей Esc и своими кнопками; клик по фону по-прежнему не закрывает.
- В таблице «Модели» колонка «Адрес API» заменена колонкой «Модель» (идентификатор модели); строка с идентификатором под названием убрана. Поиск по адресу остаётся.
- **BREAKING:** нет.
