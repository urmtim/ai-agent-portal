# Proposal

## Why

«Базовый ассистент» — тот, кто отвечает в чате, — сейчас не настраивается: работает на модели по умолчанию и может звать любого включённого агента и инструмент «Траты». Пользователь хочет управлять им как агентом: задать модель и явно разрешить, к каким агентам, MCP-серверам и API он может обращаться. Чего не разрешили — к тому ассистент не обращается.

Заодно убирается демо-агент «Чеки из почты», который создавался в новой базе сам.

## What Changes

- Страница настройки базового ассистента `/agents/assistant` (открывается кликом по его строке в «Агентах»):
  - модель: «По умолчанию» или одна из реестра;
  - агенты: отметки по агентам пользователя;
  - MCP: отметки по MCP-серверам (раздела MCP пока нет — список пуст с пояснением);
  - API: отметки по API портала; пока одно — «Траты» (сводка трат по чекам).
  - Сохранение пишется в журнал.
- По умолчанию ничего не разрешено: ассистент просто разговаривает. **BREAKING:** в чате больше нет «Трат» и запуска агентов, пока их не разрешили в настройках.
- Строка «Базовый ассистент» в «Агентах» перестаёт быть приглушённой: показывает его модель и что ему разрешено, кликом открывает настройки.
- Чат: модель «по умолчанию» для чата — модель ассистента, если задана, иначе модель по умолчанию из реестра. Подсказки на пустом чате зависят от разрешённого.
- Демо-агент «Чеки из почты» больше не создаётся при заполнении новой базы (тип агента остаётся, его можно создать вручную).

## Capabilities

### New Capabilities
- `assistant-settings`: настройки базового ассистента — модель и разрешённые агенты, MCP и API.

### Modified Capabilities
- `agents-list`: строка «Базовый ассистент» настраиваемая.
- `chat`: инструменты по разрешениям ассистента; модель ассистента как модель по умолчанию чата.

## Impact

- Prisma: модель `Assistant` (по одной на пользователя), `prisma db push`.
- `lib/assistant-config.ts` (+ тесты), `lib/assistant.ts`, `app/(app)/agents/assistant/`, `app/(app)/agents/page.tsx`.
- `app/api/chat/route.ts`, `lib/chat/tools.ts`, `app/(app)/chat/actions.ts`, `app/(app)/chat/data.ts`, `app/(app)/chat/ChatThread.tsx`.
- `prisma/seed.ts` — без демо-агента.
