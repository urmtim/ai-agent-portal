## MODIFIED Requirements

### Requirement: Настройки ассистента
Каждый пользователь SHALL иметь свои настройки базового ассистента в модальном окне «Базовый ассистент» на странице «Агенты»: модель («По умолчанию» или модель из реестра) и вкладки «Агенты», «MCP», «API» с табличными частями разрешённого. На вкладке SHALL быть таблица добавленных элементов (Название, Описание, кнопка «Убрать») и строка добавления с выбором из ещё не добавленных элементов (свои агенты пользователя, MCP-серверы, API портала — пока «Траты»). Если добавить нечего, вместо выбора MUST показываться пояснение, где такие элементы создаются. Изменения SHALL применяться по «Сохранить» и записываться в журнал.

#### Scenario: Разрешить агента
- **WHEN** пользователь на вкладке «Агенты» выбирает «Чеки из почты», нажимает «Добавить» и сохраняет
- **THEN** появляется уведомление «Настройки сохранены», а при повторном открытии агент есть в таблице

#### Scenario: Убрать элемент
- **WHEN** пользователь убирает «Траты» из таблицы на вкладке «API» и сохраняет
- **THEN** ассистент больше не обращается к тратам, «Траты» снова доступны для добавления

#### Scenario: Нечего добавить
- **WHEN** у пользователя нет MCP-серверов
- **THEN** на вкладке «MCP» вместо выбора — пояснение, что серверы добавляют в разделе MCP

#### Scenario: Удалённый агент
- **WHEN** разрешённого агента удалили
- **THEN** в настройках его больше нет, ассистент к нему не обращается
