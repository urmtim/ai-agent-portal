# Proposal

## Why

Окно модели, обкатанное на макете, устроено иначе, чем сейчас в портале:
- поля разложены по вкладкам «Общее · Параметры · YAML»;
- список моделей приходит с сервера;
- ошибки показываются сверху вниз;
- «Сохранить» неактивна, пока ничего не изменено.

Кроме того, пользователь решил отказаться от «модели по умолчанию». Сейчас она молча подменяет модель агента, если своей нет или её удалили. Нужно, чтобы модель всегда была выбрана явно, а удалить модель, на которой кто-то работает, было нельзя.

## What Changes

- **BREAKING:** «Модели по умолчанию» больше нет.
  - Убираются переключатель, пометка в таблице и ключ `default` в YAML.
  - У Ассистента и у каждого агента модель выбрана явно. Новый агент получает модель Ассистента.
  - Первая добавленная модель становится моделью Ассистента и агентов, у которых модели ещё нет.
  - Запасного варианта при вызове LLM нет. Если модель не выбрана, вызов падает с понятной ошибкой. `.env` используется только когда своих моделей нет совсем.
  - Модель, которую используют Ассистент или агенты, удалить нельзя: окно называет, кто её использует.
- У модели появляется **описание**. Оно видно в таблице под названием и попадает в YAML.
- Окно модели получает вкладки «Общее · Параметры · YAML»:
  - «Общее» — Название*, Описание.
  - «Параметры» — Адрес API*, Токен*, «Проверить», Модель*, Контекст*.
    - «Проверить» запрашивает у сервера список моделей и показывает короткий итог: «✓ Подключено. Моделей: N», «⚠ Список моделей недоступен — впишите вручную», «✕ Неверный токен», «✕ Сервер не отвечает».
    - «Модель» — поле с собственным выпадающим списком (по алфавиту, с фильтром при вводе). Название можно вписать вручную. Сама модель не выбирается никогда.
  - «YAML» — кнопки «Скачать» и «Загрузить» без цвета. Перед загрузкой окно спрашивает «Загрузить YAML? Текущие настройки будут заменены данными из файла.».
  - Шапка: только название и ×.
- «Сохранить» проверяет поля сверху вниз и показывает одну ошибку под первым неверным полем. Название модели, вписанное вручную (не из списка), сервер проверяет тестовым запросом: «Сервер не знает модель «…»».
- Окна модели, агента и Ассистента:
  - при правке «Сохранить» неактивна, пока ничего не изменено;
  - × и Esc при несохранённых изменениях спрашивают «Закрыть без сохранения? Изменения будут потеряны.»;
  - у нового объекта «Сохранить» всегда активна.
- В окне агента переключатель «Включён» переезжает в шапку, рядом с ×.
- Кнопка показа токена — значок глаза вместо эмодзи (окна модели и MCP).

### Modified Capabilities
- `llm-models`:
  - окно модели;
  - описание;
  - проверка со списком моделей;
  - нет модели по умолчанию;
  - запрет удаления используемой модели;
  - порядок выбора модели.
- `agents-list`:
  - колонка «Модель»;
  - модель нового агента;
  - «Включён» в шапке окна;
  - несохранённые изменения.
- `chat`: модель чата — только модель Ассистента.

## Impact

- **Данные:**
  - `prisma/schema.prisma`: `LlmModel.description`; `isDefault` остаётся только для переноса данных.
  - `prisma/fix-data.ts`: явная модель Ассистенту и агентам.
- **Модели:**
  - `lib/llm-pick.ts`, `lib/llm.ts` (+ список моделей), `lib/model-spec.ts`;
  - `app/(app)/models/*`.
- **Агенты:** `app/(app)/agents/*`, `lib/assistant*`.
- **Чат:** `app/(app)/chat/data.ts`.
- **Компоненты:**
  - `components/ui/Modal.tsx` (вопрос при закрытии, слот в шапке);
  - новые `ModelPicker` и иконка глаза;
  - `app/globals.css`.
