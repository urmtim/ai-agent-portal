## ADDED Requirements

### Requirement: Краткие результаты инструментов
Модель SHALL получать результаты инструментов из сообщений до текущего вопроса в кратком виде: у найденных писем — без начала текста, у прочитанного письма — не больше 300 символов текста, у запуска агента — без журнала. Сохранённая история MUST NOT меняться.

#### Scenario: Старые письма короче
- **WHEN** пользователь нашёл письма, а потом задал следующий вопрос
- **THEN** модель получает у прошлых писем id, дату, отправителя и тему, без начала текста

### Requirement: Пересказ начала чата
Когда оценка объёма истории для модели больше 70 % поля «Контекст, токенов» её модели, начало чата (кроме текущего вопроса) SHALL сжиматься этой моделью в пересказ, который хранится у чата и передаётся модели вместо пересказанных сообщений. Пересказ MUST сбрасываться, если пересказанная часть изменилась. Ошибка пересказа MUST NOT мешать ответу. В чате SHALL быть линия «Выше — пересказано для модели»; в журнал пишется «История чата сжата».

#### Scenario: Пересказ
- **WHEN** история чата больше 70 % контекста модели
- **THEN** начало чата заменяется для модели пересказом, ответ приходит, в чате видна линия «Выше — пересказано для модели»

#### Scenario: Правка пересказанного
- **WHEN** пользователь изменил сообщение из пересказанной части
- **THEN** пересказ сбрасывается, модель снова получает историю с начала
