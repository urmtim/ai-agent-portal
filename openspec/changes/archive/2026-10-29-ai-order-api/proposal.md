# Proposal

## Why

Пользователь хочет порядок раздела AI «Модели · Агенты · MCP · API»: сначала то, без чего ничего не работает (модель), потом агенты и их инструменты. Нужен и новый раздел «API».

## What Changes

- Порядок группы AI везде — в трее, во вкладках раздела и в меню по умолчанию: Модели, Агенты, MCP, API.
- Меню по умолчанию: Чат, Модели, Агенты, MCP, API. У кого в браузере сохранено прежнее меню по умолчанию (Чат, Агенты, MCP, Модели) и он его не менял, меню само переходит на новое; настроенное вручную меню не трогается.
- Новый раздел «API» по адресу `/api-access`: пока страница-заглушка с заголовком и вкладками AI; содержимое — отдельным изменением, когда будет понятно, что в нём нужно.
- **BREAKING:** нет.
