## MODIFIED Requirements

### Requirement: Инструкция и HITL
У агента SHALL быть системная инструкция и «Подтверждение действий (HITL)» — список: «Спрашивать перед изменением и отправкой» (по умолчанию), «Спрашивать только перед отправкой», «Не спрашивать». Пока подтверждение конкретных действий не сделано, при любом варианте, кроме «Не спрашивать», ассистент в чате MUST спрашивать пользователя перед запуском агента; при «Не спрашивать» — запускать сразу.

#### Scenario: Без подтверждения
- **WHEN** у агента HITL «Не спрашивать» и ассистент решает его запустить
- **THEN** агент выполняется без карточки «Нужно подтверждение»

### Requirement: Гардрейлы
У агента SHALL быть табличная часть «Гардрейлы» (без общего выключателя) с колонкой «Вид»: встроенные — «Маскирование ПДн», «Лимит шагов — N» (1–10), «Запрещённая тема — …» (несколько) — и документы из раздела «Гардрейлы». При маскировании адреса почты, телефоны, номера карт и паспортов в задаче и в результатах инструментов MUST заменяться на метки до отправки модели. Без строки «Лимит шагов» лимит — 5 шагов. У нового агента по умолчанию стоят «Маскирование ПДн» и «Лимит шагов — 5».

#### Scenario: Маскирование
- **WHEN** у агента в гардрейлах есть «Маскирование ПДн» и в письме есть телефон +7 912 345-67-89
- **THEN** модель получает «[телефон]» вместо номера

#### Scenario: Гардрейлы выключены
- **WHEN** пользователь убрал из гардрейлов «Маскирование ПДн»
- **THEN** модель получает данные без меток

### Requirement: YAML
Окно агента SHALL иметь вкладку «YAML» (крупный шрифт, подсветка) с описанием всего агента: название, «включён», модель, инструкция, HITL (`changes_and_send`, `send_only`, `off`), гардрейлы списком (`maskPii`, `maxSteps`, `forbiddenTopic`, `document` — по названию), подключения MCP с доступом, субагенты, API. Правка YAML MUST заполнять остальные вкладки, правка в них — обновлять YAML. Пароли, токены и тексты документов MUST NOT попадать в YAML. YAML прежних версий SHALL читаться.

#### Scenario: Форма и YAML
- **WHEN** пользователь меняет в YAML лимит шагов на 3
- **THEN** на вкладке «Политики» в таблице гардрейлов видно «Лимит шагов — 3»
