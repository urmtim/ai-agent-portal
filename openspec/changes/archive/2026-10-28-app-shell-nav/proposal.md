# Proposal

## Why

Сейчас шапка портала — фиксированный ряд из шести ссылок (Обучение, Траты, Агенты, Прогресс, Люди, Доступы). Портал смещается к AI-агентам, разделов станет больше, и плоский ряд перестанет помещаться. В макете `mockups/portal-all-screens.html` уже согласована новая навигация: короткое верхнее меню, которое каждый настраивает под себя, и «все разделы» за кнопкой с девятью точками.

## What Changes

- Шапка перестраивается по макету: по центру кнопка «Все разделы» (9 точек) и верхнее меню, справа — пользователь. Логотип «Семейный портал» из шапки убирается.
- Появляется выпадающий трей «Все разделы» с группами: **Основное** (Чат), **AI** (Агенты, MCP, Модели), **Семья (скрыто)** (Обучение, Траты, Прогресс), **Админ** (Пользователи, Доступы — только для администратора).
- Верхнее меню показывает закреплённые пункты; по умолчанию — Чат, Агенты, MCP, Модели.
- Закрепление и порядок:
  - перетаскивание пункта из трея в меню закрепляет его;
  - перетаскивание пункта из меню обратно в трей открепляет его;
  - перетаскивание внутри меню меняет порядок.
- Выбор сохраняется в браузере.
- Если открыт раздел, которого нет в меню, в конце меню появляется временная вкладка с подсветкой и кнопкой-булавкой «Закрепить в меню» (видна при наведении). Текущий раздел подсвечивается и в трее.
- Дочерние страницы подсвечивают родительский раздел: карточка агента → Агенты, курс и урок → Обучение.
- Новые адреса-заглушки `/chat`, `/mcp`, `/models` с заголовком раздела, чтобы меню вело на реальные страницы. Наполнение — отдельными изменениями.
- **BREAKING** (для пользователя): пункты «Люди» переименованы в «Пользователи», раздел «Траты»/«Прогресс»/«Обучение» по умолчанию не в верхнем меню, а в трее.

## Capabilities

### New Capabilities
- `app-navigation`: главная навигация портала — шапка, трей всех разделов с группами, закреплённые пункты верхнего меню (закрепление, открепление, порядок, сохранение), подсветка текущего раздела и временная вкладка, видимость админских разделов.

## Impact

- Код:
  - `components/Header.tsx`, `components/NavLink.tsx` (заменяется клиентским меню);
  - новый клиентский компонент меню с треем;
  - `app/globals.css` (стили шапки и трея из макета);
  - `UserMenu` остаётся.
- Новые страницы: `app/(app)/chat/page.tsx`, `app/(app)/mcp/page.tsx`, `app/(app)/models/page.tsx` (заглушки за авторизацией).
- Данные: только `localStorage` браузера; база и API не меняются.
- Зависимости: новых нет (нативный HTML5 drag-and-drop).
