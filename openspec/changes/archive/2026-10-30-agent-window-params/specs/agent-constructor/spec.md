## MODIFIED Requirements

### Requirement: YAML
Окно агента SHALL иметь вкладку «YAML» (крупный шрифт, подсветка) с описанием всего агента: название, описание (`description`), «включён», модель, инструкция, HITL (`changes_and_send`, `send_only`, `off`), гардрейлы списком (`maskPii`, `maxSteps`, `forbiddenTopic`, `document` — по названию), подключения MCP с доступом, субагенты, API. Правка YAML MUST заполнять остальные вкладки, правка в них — обновлять YAML. Пароли, токены и тексты документов MUST NOT попадать в YAML. YAML прежних версий SHALL читаться; без `description` описание пустое.

#### Scenario: Форма и YAML
- **WHEN** пользователь меняет в YAML лимит шагов на 3
- **THEN** на вкладке «Политики» в таблице гардрейлов видно «Лимит шагов — 3»

#### Scenario: Описание в YAML
- **WHEN** пользователь пишет в YAML `description: Утренняя сводка`
- **THEN** на вкладке «Общее» в поле «Описание» видно «Утренняя сводка»
