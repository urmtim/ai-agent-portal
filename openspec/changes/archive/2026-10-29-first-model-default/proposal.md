# Proposal

## Why

Когда моделей ещё нет, добавленная модель всё равно становится моделью по умолчанию, хотя переключатель «Сделать моделью по умолчанию» в окне выключен. Окно должно показывать, что произойдёт.

## What Changes

- В окне новой модели, если у пользователя ещё нет моделей, переключатель «Сделать моделью по умолчанию» включён и заблокирован, под ним — «Это первая модель — она всегда становится моделью по умолчанию».
- У модели по умолчанию (при правке) — пояснение, как сменить модель по умолчанию.
- **BREAKING:** нет.
