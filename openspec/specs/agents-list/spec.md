# agents-list Specification

## Purpose
Страница «Агенты» — таблица ИИ-агентов пользователя, откуда их создают, запускают, настраивают и удаляют.

## Requirements

### Requirement: Таблица агентов
Страница `/agents` SHALL показывать агентов текущего пользователя таблицей. Колонки:
- ID;
- Название — с описанием, название ведёт на страницу агента;
- Модель — название модели агента; если своя не выбрана — модели по умолчанию; если моделей нет нигде — «не задана»;
- MCP — какие инструменты использует агент, для «Чеков» это «Почта»;
- Статус — «включён» или «выключен»;
- Последний прогон — дата и итог или «—».

Поиск и фильтр по статусу работают как у всех списков. Чужие агенты MUST NOT показываться.

#### Scenario: Агент с прогоном
- **WHEN** у пользователя есть агент «Чеки из почты», который запускался
- **THEN** в строке видна дата последнего прогона и его итог

#### Scenario: Агент на модели по умолчанию
- **WHEN** у агента не выбрана своя модель, а по умолчанию — GLM-4
- **THEN** в колонке «Модель» видно «GLM-4»

### Requirement: Ассистент
Первой строкой таблицы SHALL идти «Ассистент» (с ним говорят в чате, агенты — его исполнители) с пометкой «встроенный» и ID «#1» (агенты пользователя нумеруются с «#2» в порядке создания): его модель, разрешённые MCP-серверы и краткая сводка разрешённого (агенты, API). Клик по строке или иконка «Изменить» SHALL открывать модальное окно «Ассистент» с его настройками. Строку нельзя удалить или запустить; она не участвует в фильтре по статусу.

#### Scenario: Пустой список
- **WHEN** у пользователя нет своих агентов
- **THEN** в таблице только строка «Ассистент»

#### Scenario: Открыть настройки
- **WHEN** пользователь кликает по строке «Ассистент»
- **THEN** открывается окно «Ассистент» с его настройками

### Requirement: Создание агента
Кнопка «Новый агент» SHALL открывать модалку с выбором типа и полем «Название». Пока доступен один тип — «Чеки из почты», он создаётся с настройками по умолчанию. Пустое название заменяется названием типа.

#### Scenario: Создать
- **WHEN** пользователь выбирает «Чеки из почты» и нажимает «Создать»
- **THEN** в таблице появляется новый агент, видно «Агент создан»

### Requirement: Запуск агента
Иконка «Запустить» SHALL запускать агента сразу. Пока идёт прогон, иконка неактивна. После прогона обновляются колонка «Последний прогон» и уведомление с итогом.

#### Scenario: Запуск без настроенной почты
- **WHEN** почта не настроена и пользователь запускает «Чеки»
- **THEN** прогон завершается с ошибкой, в «Последний прогон» видна ошибка

### Requirement: Настройка и удаление агента
Иконка «Изменить» (✎) и клик по строке SHALL открывать модальное окно «Изменить агента» с полями: Название, Модель, За сколько дней смотреть, Макс. писем за прогон, Фильтр по отправителю, «Агент включён». Название агента в строке SHALL вести на страницу агента с запуском и историей прогонов; там же кнопка «Изменить» открывает то же окно. Иконка «Удалить» SHALL после подтверждения удалять агента вместе с историей прогонов. Чеки, которые агент уже собрал, остаются.

#### Scenario: Удалить агента
- **WHEN** пользователь подтверждает удаление агента
- **THEN** строка исчезает, появляется «Агент удалён»

#### Scenario: Изменить агента
- **WHEN** пользователь кликает по строке агента, меняет название и нажимает «Сохранить»
- **THEN** окно закрывается, появляется «Сохранено», в строке новое название

### Requirement: Подсказка о настройке
Если у пользователя есть агент, которому нужна почта, а почта не настроена (`.env`), или нет ни одной LLM (ни в реестре моделей, ни в `.env`), над таблицей SHALL показываться предупреждение, чего не хватает: для почты — зачем она агенту и названия переменных, для LLM — ссылка на раздел «Модели». Без почтовых агентов предупреждение про почту MUST NOT показываться. Значения переменных MUST NOT показываться.

#### Scenario: Нет LLM
- **WHEN** реестр моделей пуст и не заданы `LLM_BASE_URL` / `LLM_MODEL`
- **THEN** видно предупреждение со ссылкой «добавьте модель в разделе «Модели»»

#### Scenario: Модель в реестре
- **WHEN** в реестре есть модель по умолчанию, а `LLM_*` в `.env` пусты
- **THEN** предупреждения про LLM нет

#### Scenario: Нет почтовых агентов
- **WHEN** почта не настроена, но у пользователя нет агента «Чеки из почты»
- **THEN** предупреждения про почту нет
