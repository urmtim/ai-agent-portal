# assistant-settings Specification

## Purpose
Настройки базового ассистента чата: на какой модели он работает и к каким агентам, MCP-серверам и API ему можно обращаться.

## Requirements

### Requirement: Настройки ассистента
Каждый пользователь SHALL иметь свои настройки ассистента. ✎ в строке «Ассистент» SHALL открывать то же окно, что и у агента («Общее · Политики · Субагенты · MCP · API · YAML»), с заблокированными «Агент включён» (всегда включён), «Название» («Ассистент»), «Системная инструкция» и «Тест-запуск» (проверяют в чате). В поле «Системная инструкция» SHALL показываться постоянная инструкция чата — ровно тот текст, что получает модель; политики и дата в неё не вписываются, модель получает их инструментами. Модель — одна из своих моделей, по умолчанию — модель по умолчанию. Гардрейлы ассистента (маскирование результатов почты, лимит шагов, темы, документы) MUST действовать в чате. На вкладках «Субагенты», «MCP», «API» SHALL быть табличные части с поиском, фильтром и «Добавить», без поясняющих подсказок; если добавить нечего, «Добавить» неактивна, а таблица показывает «Пока ничего не добавлено». Изменения SHALL применяться по «Сохранить» и записываться в журнал.

#### Scenario: Разрешить агента
- **WHEN** пользователь на вкладке «Субагенты» нажимает «Добавить», выбирает агента и сохраняет
- **THEN** появляется уведомление «Настройки сохранены», а при повторном открытии агент есть в таблице

#### Scenario: Убрать элемент
- **WHEN** пользователь убирает агента из таблицы на вкладке «Субагенты» и сохраняет
- **THEN** ассистент больше не может запускать этого агента, агент снова доступен для добавления

#### Scenario: Нечего добавить
- **WHEN** у пользователя нет MCP-серверов
- **THEN** на вкладке «MCP» кнопка «Добавить» неактивна, таблица пуста

#### Scenario: Удалённый агент
- **WHEN** разрешённого агента удалили
- **THEN** в настройках его больше нет, ассистент к нему не обращается

#### Scenario: API пока нет
- **WHEN** пользователь открывает вкладку «API»
- **THEN** таблица пуста, «Добавить» неактивна

#### Scenario: Заблокированные поля
- **WHEN** пользователь открывает окно «Ассистент»
- **THEN** «Агент включён», «Название», «Системная инструкция» и «Тест-запуск» видны, но недоступны, остальное редактируется

#### Scenario: Настоящая инструкция
- **WHEN** пользователь открывает окно «Ассистент»
- **THEN** в «Системной инструкции» тот же текст, что модель получает в чате, без даты и без содержимого политик

### Requirement: Ничего не разрешено по умолчанию
Пока пользователь не разрешил агента, MCP-сервер или API, ассистент MUST NOT к ним обращаться. Новые настройки SHALL начинаться с пустых списков и модели по умолчанию пользователя, выбранной в списке моделей.

#### Scenario: Новый пользователь
- **WHEN** пользователь впервые открывает настройки ассистента
- **THEN** ни один агент, MCP-сервер и API не отмечен
