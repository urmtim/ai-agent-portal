# assistant-settings Specification

## Purpose
Настройки базового ассистента чата: на какой модели он работает и к каким агентам, MCP-серверам и API ему можно обращаться.

## Requirements

### Requirement: Настройки ассистента
Каждый пользователь SHALL иметь свои настройки ассистента в модальном окне «Ассистент» на странице «Агенты»: модель («По умолчанию» или модель из реестра) и вкладки «Агенты», «MCP», «API» с табличными частями разрешённого. На вкладке SHALL быть таблица добавленных элементов (Название, Описание, кнопка «Убрать») и строка добавления с выбором из ещё не добавленных элементов (свои агенты пользователя, MCP-серверы, API портала — пока ни одного). Если добавить нечего, вместо выбора MUST показываться пояснение, где такие элементы создаются. Изменения SHALL применяться по «Сохранить» и записываться в журнал.

#### Scenario: Разрешить агента
- **WHEN** пользователь на вкладке «Агенты» выбирает «Чеки из почты», нажимает «Добавить» и сохраняет
- **THEN** появляется уведомление «Настройки сохранены», а при повторном открытии агент есть в таблице

#### Scenario: Убрать элемент
- **WHEN** пользователь убирает агента из таблицы на вкладке «Агенты» и сохраняет
- **THEN** ассистент больше не может запускать этого агента, агент снова доступен для добавления

#### Scenario: Нечего добавить
- **WHEN** у пользователя нет MCP-серверов
- **THEN** на вкладке «MCP» вместо выбора — пояснение, что серверы добавляют в разделе MCP

#### Scenario: Удалённый агент
- **WHEN** разрешённого агента удалили
- **THEN** в настройках его больше нет, ассистент к нему не обращается

#### Scenario: API пока нет
- **WHEN** пользователь открывает вкладку «API»
- **THEN** таблица пуста, вместо выбора — «API портала пока нет»

### Requirement: Ничего не разрешено по умолчанию
Пока пользователь не разрешил агента, MCP-сервер или API, ассистент MUST NOT к ним обращаться. Новые настройки SHALL начинаться с пустых списков и модели «По умолчанию».

#### Scenario: Новый пользователь
- **WHEN** пользователь впервые открывает настройки ассистента
- **THEN** ни один агент, MCP-сервер и API не отмечен
